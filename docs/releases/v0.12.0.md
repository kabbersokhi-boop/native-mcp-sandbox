# Native MCP Sandbox v0.12.0

This release strengthens the contract between the native C++ evidence server and the external
Python investigation client.

## Security and protocol changes

- Negotiate MCP revision `2025-11-25` and reject unsupported revisions and null request IDs.
- Capture and enforce closed output schemas before native results become agent evidence.
- Bound tool-list pagination, structured evidence, strings, finite numbers, and response bytes.
- Extend secret redaction through tuple-backed structured values.
- Exercise the real Python client against the real C++ server in the integration gate.

## Release evidence

The release workflow publishes:

- a Linux x86-64 native package;
- the external Python client as a wheel and source archive;
- SPDX JSON SBOMs for source and installed native files;
- `SHA256SUMS` for every downloadable asset;
- GitHub build-provenance attestations bound to the release commit.

The C++ process remains stdio-only and has no provider SDK, credential, or network client. The
Python client is a separate process and cannot add authority to the native tool surface.

See [Assurance and verification](../ASSURANCE.md) for scope and limitations.
