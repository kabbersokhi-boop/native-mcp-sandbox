# Native MCP Sandbox v0.13.0 candidate

Status: source version v0.13.0; a tagged release has not been published.

A client that stopped reading could previously block native protocol writes and shutdown.
The descriptor transport now bounds each write, handles partial writes and closed pipes, and
closes admission on failure. The scheduler cooperatively cancels accepted work. Normal EOF
retains drain semantics. This does not promise hard real-time interruption of filesystem calls.

The installed `native-mcp-agent demo` command exercises all four C++ tools. Its three scenarios
show observed recovery, insufficient evidence and separate native/Python rejection layers.
Reports carry correlated evidence references and explicit unresolved questions.

The candidate also includes independent official-SDK interoperability, direct native boundary
evaluation, native resource measurements, a static trace viewer and a recorded walkthrough.
Release packaging now verifies the extracted native archive and installed wheel together.

The authority boundary remains read-only. No shell, native network API or host-evidence egress
mode is added. Candidate evidence is indexed in [the implementation record](../FLAGSHIP_PROGRESS.md).
